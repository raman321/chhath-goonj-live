# 🪔 Chhath Goonj (छठ गूंज)

> **"छठी मइया के पावन गीत... अविरल भक्ति प्रवाह"**  
> *An ad-free, non-commercial digital radio platform bringing 24/7 uninterrupted Chhath Puja melodies to devotees worldwide.*

---

## ✨ Overview

**Chhath Goonj** is a dedicated devotional web platform crafted with love and devotion for **Chhathi Maiya & Lord Surya**. Designed to deliver seamless, uninterrupted audio streaming of sacred Chhath bhajans and geet, it offers a serene, ad-free listening experience for all devotees.

🔗 **Live Website:** [https://chhathgoonj.live/](https://chhathgoonj.live/)

---

## 🌟 Key Features

* **🪔 24/7 Uninterrupted Stream:** Continuous play of traditional and sacred Chhath melodies.
* **🚫 100% Ad-Free & Non-Commercial:** No pop-ups, mid-roll ads or commercial interruptions.
* **📱 Responsive Design:** Optimized for smooth playback on mobile phones, tablets, and desktop computers.
* **🙏 Devotional Community:** Real-time live devotee counter and interactive sharing.
* **❤️ Voluntary Support System:** Optional modal for voluntary contributions to cover server and streaming bandwidth costs.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Audio Streaming:** Web Audio / Audio Stream API
* **Hosting & Deployment:** Netlify
* **Domain:** `.live` custom domain configuration
